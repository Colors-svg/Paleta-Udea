NORMATIVA DE APLICACIÓN Y RATIO DE USO (60 / 30 / 10)

  • 60% Dominante Primario: Verdes (349 C, 7740 C, 334 C) y Neutros claros (#F8FAFC) para estructurar el 60% del espacio visual de cualquier composición.
  • 30% Soporte & Contenido: Gama esmeralda, menta y neutros oscuros (#0F172A) en tipografía, contenedores, tarjetas y diagramas.
  • 10% Acento & Interacción: Gama secundaria (137 C ámbar, 032 C coral, 633 C azul) reservada estrictamente a botones de acción (CTA), estados y gráficos.

ACCESIBILIDAD DIGITAL WCAG 2.1 & PERFILES DE SALIDA

  • Contraste Alto (AAA): Fondos oscuros 349 C, 7718 C, 7650 C y 100-7 C requieren tipografía blanca pura (#FFFFFF) para superar un ratio de contraste de 7:1.
  • Contraste Claro (AA): Fondos luminosos 375 C lima, 7465 C menta y 137 C ámbar exigen texto grafito oscuro (#0F172A) con ratio superior a 4.5:1.
  • Impresión Offset / Digital: Usar tintas directas Pantone Formula Guide Coated o separación cuatricromía calibrada bajo estándar FOGRA39.
